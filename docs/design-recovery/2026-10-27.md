## Repository-specific records

### D14 — Kozo Dreams: living paper and a traceable composition studio

**Use when:** When recovering Kozo Dreams, dark-washi fantasy, pattern composition, narrative navigation, or the v3 architecture.

[Recovered intent] DESIGN_SYSTEM.md traces four image references into paper-library structure, dark print texture, whimsical floating architecture, and calligraphic ribbon motion. Kozo Dreams should feel like a handmade book with moving illustrations, kirigami windows, fibers, ink, and unusual creatures.

[Design DNA] Retain indigo Ai-Iro, brown Kakishibu, pink Sakura, purple Kyo-Murasaki, Sumi ink, warm paper/night-paper layers, Noto Japanese serif/sans roles, restrained decorative script, deckle edges, and authored glyph/pattern provenance. The named component horizon includes KirigamiCard, RibbonHeading, PaperButton, KozoFiberCanvas, PatternComposer, PaletteAlchemist, ScrollTaleEngine, and LivingMascot.

[Observed maturity] The v3 audit reports a five-layer ownership model and seven-stage flow—Threshold, Discover, Compose, Refine, Validate, Govern, Remember—with semantic event traces. It also reports missing WebP assets, incomplete registry coverage, omitted loading/disabled study states, and missing production QA. Those are historical audit results, not rerun acceptance.

[Repair resolution — proposed] Reconcile the original visual canon with the v3 behavioral architecture rather than replacing the fantasy with inspection UI. Locate actual missing assets; do not silently substitute placeholders. Preserve the rule that a primitive renders a state while a flow owns transitions. Validate the actual v3 directory before framework migration; a v3-react package file is not evidence of a complete port.

[Reimagined horizon] A paper-based creative instrument in which users explore a pattern, compose a variation, understand its rules, and retain a story/decision trail. The inspector is a companion to the dream, not the hero of every screen.

[Carry-forward test] Complete one seven-stage journey with real assets, visible loading/disabled/error behavior, preserved motif provenance, export/reload, keyboard access, and a low-motion version that still feels like living paper.
